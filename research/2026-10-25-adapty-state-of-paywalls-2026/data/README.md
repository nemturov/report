# Сохранённые числовые данные

## chart-data.json

Точный объект `D` из `sources/web/report-1.86edeffa.js`: 19 наборов. JSON извлечён без округления и без исполнения стороннего JavaScript. Другие графики и их определения также сохранены в полном JS и таблицах скилла, но не все входят в объект D.

| Ключ | Содержание |
|---|---|
| v2p | view→paid за 30 дней |
| v2t | view→trial, приложения с trial |
| t2p | trial→paid |
| cancel | cancel_1h и cancel_24h |
| xy | отмены за сутки и trial→paid по категориям |
| fy, fyRatio | динамика FY и отношение US к региону |
| price | полная цена по длительности, региону и категории |
| rev | распределение выручки по тарифам |
| plans | распределение длительностей / связанные значения исходного графика |
| ab | агрегаты тестов количества продуктов |
| buyers | поведение при предвыборе |
| presel | частоты предвыбранных планов |
| life | lifetime |
| trialLen, trialPlan | распределение trial и сравнение групп длительности |
| useDisc, depth, winback | использование скидок, глубина и win-back |

Для `v2p/v2t/t2p/price`: plan → region → category → `[median, p25, p75, p90, N]` в полных ячейках. Сохранять отсутствие/короткие значения как есть. Проценты выражены числом 1.38 для 1,38%, цены — в USD. Значение N относится к конкретному срезу, не ко всему отчёту.

Другие массивы имеют собственные схемы. Не применять схему percentile автоматически ко всем ключам. Их подписи и преобразования проверять по оригинальному JS; например typical discount в useDisc рассчитывается как `(1 − r[4]) × 100`, а не `r[4] × 100`.
